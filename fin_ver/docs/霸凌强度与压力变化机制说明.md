# 霸凌强度与受害者压力变化控制机制

## 文档版本
- 版本：v3.0（2026-04-20更新）
- 适用系统：校园话语霸凌与教师干预实训系统

---

## 一、概述

本文档详细说明系统中两个核心指标——**霸凌强度（Bullying Intensity）** 和 **受害者压力（Victim Distress）** ——的计算逻辑、变化机制和参数配置。

### 核心设计原则

1. **因果优先**：霸凌攻击是压力增加的主要原因，情绪反馈是次要因素
2. **阻尼平滑**：压力变化不能过快，防止异常飙升
3. **正相关性**：霸凌强度下降时，压力应跟随下降
4. **干预有效**：教师心理关怀干预可显著降低压力

---

## 二、霸凌强度（Bullying Intensity）控制机制

### 2.1 定义与范围
- **定义**：当前对话中霸凌行为的激烈程度
- **范围**：0.0 ~ 1.0（0% ~ 100%）
- **初始值**：根据场景难度等级设定

### 2.2 初始值对照表

| 难度等级 | 霸凌强度初始值 | 压力初始值 | 场景描述 |
|---------|---------------|-----------|---------|
| 1 | 15% | 20% | 轻度冲突 |
| 2 | 30% | 35% | 明显霸凌 |
| 3 | 45% | 50% | 严重霸凌 |
| 4 | 60% | 65% | 高度严重 |
| 5 | 75% | 80% | 极端情况 |

### 2.3 敌意评分计算

系统通过关键词匹配计算消息的**敌意评分（Hostile Score）**：

```python
敌意评分 = Σ (匹配关键词数 × 类别权重)
```

#### 敌意关键词类别与权重

| 类别 | 权重 | 示例关键词 |
|-----|------|----------|
| 外貌嘲笑 | 0.20 | 丑、难看、土、脏 |
| 背景嘲笑 | 0.25 | 穷、穷鬼、没钱、买不起 |
| 人格攻击 | 0.30 | 垃圾、废物、智障、变态 |
| 能力嘲笑 | 0.20 | 画得丑、什么破、可笑 |
| 威胁恐吓 | 0.35 | 打死、弄死、滚远点 |
| 排挤孤立 | 0.20 | 不带你、别跟着、滚 |

#### 升级词加成
消息中包含"又"、"总是"、"每次"、"从来"等升级词时，敌意评分额外+0.2。

### 2.4 霸凌强度变化规则

#### 增加条件
- **触发**：霸凌者消息敌意评分 ≥ 0.3（阈值）
- **增幅**：`新霸凌强度 = 旧霸凌强度 + 敌意评分 × 0.15`

#### 减少条件
- **教师有效干预**：根据干预质量评分，减少5%~25%
- **旁观者强力支持**：支持评分 > 0.2时，间接影响

## 三、受害者压力（Victim Distress）控制机制

### 3.1 定义与范围
- **定义**：受害者心理压力/痛苦程度
- **范围**：0.0 ~ 1.0（0% ~ 100%）
- **初始值**：根据场景难度等级设定（见表2.2）

### 3.2 压力变化四大因素

```
压力变化 = 攻击加压 + 情绪反馈 - 干预减压 - 自然恢复
```

### 3.3 攻击加压机制（主要因素）

当霸凌者发送敌意消息时，受害者压力增加：

```python
压力增量 = 敌意评分 × 0.04 × 阻尼因子 × 韧性因子
```

**参数说明**：
- `0.04`：霸凌→压力转换率（bully_attack_distress_rate）
- `阻尼因子`：当前压力越高，增长越慢（详见3.6）
- `韧性因子`：干预后短期内压力增长减缓（详见3.7）

### 3.4 情绪反馈机制（次要因素）

受害者自身情绪表达会影响压力：

| 情绪类型 | 基础增量 | 实际增量公式 |
|---------|---------|------------|
| 悲伤(sad) | 0.12 | 0.12 × 0.3 × 情绪阻尼 × 韧性因子 |
| 恐惧(fearful) | 0.18 | 0.18 × 0.3 × 情绪阻尼 × 韧性因子 |
| 自我否定(self_doubt) | 0.22 | 0.22 × 0.3 × 情绪阻尼 × 韧性因子 |

**说明**：
- `0.3`：情绪反馈缩放因子，缩减情绪影响（情绪是结果不是原因）
- `情绪阻尼`：高压力时情绪词影响减弱（详见3.6）

### 3.5 支持减压机制

#### 旁观者A（仗义型）支持
- **条件**：支持评分 > 0.2
- **效果**：`压力减少 = 支持评分 × 0.35`

#### 旁观者B（从众型）支持
- **条件**：支持评分 > 0.4
- **效果**：`压力减少 = 支持评分 × 0.1`

## 四、阻尼机制详解（核心修复）

### 4.1 压力增长阻尼

**目的**：防止压力快速冲顶，模拟心理承受力的非线性特征

```python
阻尼因子 = 1.0 - (当前压力 × 0.6)
阻尼因子 = max(0.25, 阻尼因子)  # 最低保留25%增长速度
```

**阻尼效果示例**：

| 当前压力 | 阻尼因子 | 实际增长速度 |
|---------|---------|------------|
| 0% | 100% | 全速增长 |
| 30% | 82% | 增长减缓18% |
| 50% | 70% | 增长减缓30% |
| 70% | 58% | 增长减缓42% |
| 90% | 46% | 增长减缓54% |

### 4.2 情绪反馈阻尼

**目的**：高压力时，情绪表达对压力的边际影响减弱

```python
情绪阻尼 = 1.0 - (当前压力 × 0.4)
情绪阻尼 = max(0.4, 情绪阻尼)  # 最低保留40%影响
```

### 4.3 单轮增长限制

**目的**：防止一轮内压力跳跃过大

```python
MAX_DISTRESS_INCREASE_PER_ROUND = 0.12  # 单轮最多+12%
```

## 五、干预韧性缓冲机制

### 5.1 定义

教师有效干预后，受害者在短期内获得"心理韧性"，压力增长速度减缓。

### 5.2 参数配置

| 参数 | 值 | 说明 |
|-----|---|------|
| 持续轮数 | 3轮 | 干预效果持续3轮对话 |
| 韧性因子 | 0.5 | 压力增长减半 |

### 5.3 生效条件

```python
韧性生效 = (
    上次干预有效 
    AND 距离干预轮数 ≤ 3
    AND 霸凌强度 < 0.15  # 霸凌重新活跃时失效
)
```

### 5.4 效果对比

| 场景 | 无韧性缓冲 | 有韧性缓冲 |
|-----|-----------|-----------|
| 干预后第1轮霸凌反弹 | +6% | +3% |
| 干预后第2轮霸凌反弹 | +5% | +2.5% |
| 干预后第3轮霸凌反弹 | +4% | +2% |

## 六、恢复机制

### 6.1 自然恢复

**条件**：霸凌强度 < 0.1（霸凌几乎停止）

```python
恢复量 = 0.08 + (当前压力 × 0.08)  # 基础恢复 + 压力加成
```

**说明**：压力越高，恢复越快（模拟心理弹性）

### 6.2 霸凌下降耦合

**条件**：霸凌强度较上一轮下降

```python
压力下降 = 霸凌下降幅度 × 0.3 × 1.5
```

**说明**：霸凌强度下降时，压力正相关性下降

### 6.3 低霸凌衰减

**条件**：霸凌强度 < 0.3 且 压力 > 0.03

```python
衰减量 = 0.10 × (1 + 当前压力 × 0.5)
```

### 6.4 干预减压

**条件**：本轮有有效干预且霸凌下降

```python
减压量 = 0.08 + (当前压力 × 0.1)
```

## 七、教师干预评估机制

### 7.1 干预质量评分

```python
质量评分 = 基础分 + 积极信号加分 - 消极信号扣分
```

| 组成部分 | 分值范围 | 说明 |
|---------|---------|------|
| 基础分 | 0.35~0.5 | 根据干预内容长度 |
| 积极信号 | 0~0.3 | 每个信号+0.1 |
| 消极信号 | -0.25~0 | 每个信号-0.1 |

### 7.2 积极信号关键词

| 类别 | 关键词示例 |
|-----|----------|
| 关注受害者 | 思远、你还好吗、保护、支持 |
| 共情引导 | 换位思考、如果是你、体会 |
| 反省引导 | 道歉、反省、错了、过分 |
| 规则建立 | 规则、班级、互相尊重 |
| 温和制止 | 不要、不能、停止、不合适 |
| 受害者关怀 | 不是你的错、你有才华、老师相信你 |

### 7.3 干预对霸凌强度的影响

| 质量评分 | 效果 | 霸凌强度变化 |
|---------|------|------------|
| ≥ 0.75 | 优秀 | -15% |
| 0.55~0.74 | 良好 | -10% |
| 0.35~0.54 | 一般 | -5% |
| < 0.35 | 较差 | +5% |

### 7.4 关怀度与减压

```python
关怀度 = (关怀关键词数 × 0.15) + (修复关键词数 × 0.25)
减压量 = 关怀度 × 0.5  # 当关怀度 > 0.15 时生效
```

## 九、参数配置文件

所有参数可在 `config/orchestrator.yaml` 中调整：

```yaml
# 霸凌强度参数
bullying_intensity:
  hostile_threshold: 0.3    # 敌意阈值
  increase_rate: 0.15       # 增长率

# 受害者压力参数
victim_distress:
  bully_attack_distress_rate: 0.04   # 攻击→压力系数
  emotional_feedback_scale: 0.3       # 情绪反馈缩放
  distress_bullying_coupling: 0.3     # 霸凌下降耦合
  distress_decay_rate: 0.10           # 自然衰减率
  distress_decay_threshold: 0.3       # 衰减触发阈值

# 干预减压参数
intervention_relief:
  distress_reduction_rate: 0.5        # 关怀→减压系数
  trigger_threshold: 0.15             # 触发阈值

# 旁观者支持参数
bystander_a:
  victim_distress_reduction: 0.35     # 仗义型减压力度

# 自然恢复参数
natural_recovery:
  bully_stopped_threshold: 0.1        # 霸凌停止阈值
  recovery_per_round: 0.08            # 每轮恢复量
```

## 十、机制设计理念

### 10.1 心理学依据

1. **阻尼机制**：模拟心理承受力的非线性特征，压力越高，边际增长越慢
2. **韧性缓冲**：有效心理干预后，受害者获得短期心理支持
3. **正相关性**：霸凌强度与心理压力应保持正相关，但非完全同步

### 10.2 教学设计目标

1. **真实性**：模拟真实霸凌场景中的心理变化
2. **可干预性**：教师干预具有明确且合理的正面效果
3. **平衡性**：压力变化平滑，不会异常飙升或骤降
4. **可调性**：所有参数可通过配置文件调整
