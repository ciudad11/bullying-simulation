# 霸凌强度与压力变化机制 - 快速参考

## 核心公式

### 压力变化
```
压力 = 攻击加压 × 阻尼因子 × 韧性因子 + 情绪反馈 × 情绪阻尼 - 干预减压 - 自然恢复
```

### 霸凌强度变化
```
霸凌强度 = 原强度 + 敌意评分 × 0.15    (攻击时)
霸凌强度 = 原强度 - 干预效果 × 减压系数 (干预时)
```

---

## 关键参数速查表

| 参数名 | 默认值 | 说明 |
|-------|-------|------|
| bully_attack_distress_rate | 0.04 | 霸凌攻击→压力转换率 |
| emotional_feedback_scale | 0.3 | 情绪反馈缩放（缩减70%） |
| MAX_DISTRESS_INCREASE | 0.12 | 单轮压力最大增长 |
| INTERVENTION_RESILIENCE | 3轮 | 干预韧性持续时间 |
| RESILIENCE_FACTOR | 0.5 | 韧性期内压力增长减半 |

---

## 阻尼因子计算

| 当前压力 | 阻尼因子 | 效果 |
|---------|---------|------|
| 0% | 100% | 无阻尼 |
| 50% | 70% | 减缓30% |
| 80% | 52% | 减缓48% |

---

## 干预效果速查

| 质量评分 | 霸凌强度变化 | 说明 |
|---------|-------------|------|
| ≥ 0.75 | -15% | 优秀干预 |
| 0.55-0.74 | -10% | 良好干预 |
| 0.35-0.54 | -5% | 一般干预 |
| < 0.35 | +5% | 干预不当 |
